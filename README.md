# Chrome Browser - Міні веб-браузер

Повнофункціональний міні веб-браузер з інтерфейсом, схожим на Chrome, з підтримкою fullscreen режиму та адаптивним дизайном.

## Особливості

### 🎨 Інтерфейс Chrome
- Дизайн, схожий на Google Chrome
- Вкладки з можливістю створення та закриття
- Адресний рядок з пошуком
- Навігаційні кнопки (назад, вперед, оновити, домашня сторінка)

### 🔧 Функціональність
- Відкриття веб-сторінок через iframe
- Навігація по історії для кожної вкладки
- Пошукові запити через Google
- Закладки
- Контроль масштабу (зум)

### 📱 Адаптивний дизайн
- Повністю адаптивний для мобільних пристроїв
- Адаптація інтерфейсу під розмір екрану
- Зручне використання на планшетах і телефонах

### 🖥️ Fullscreen режим
- Підтримка повноекранного режиму
- Автоматична адаптація під розмір екрана
- Зручне перемикання між звичайним і повноекранним режимами

### ⌨️ Гарячі клавіші
- **F11** - Перемикання fullscreen
- **Ctrl + R** - Оновити сторінку
- **Alt + Home** - Домашня сторінка
- **Ctrl + колесо миші** - Зміна масштабу

## Використання

1. Відкрийте `index.html` у браузері
2. Використовуйте адресний рядок для введення URL або пошукового запиту
3. Користуйтеся навігаційними кнопками для переміщення
4. Створюйте нові вкладки за потреби
5. Використовуйте fullscreen режим для кращого перегляду

## Технічні деталі

- Чистий HTML, CSS і JavaScript без зовнішніх залежностей
- Використовує iframe для відображення веб-сторінок
- Повністю клієнтська реалізація
- Підтримка сенсорних подій для мобільних пристроїв

## Примітки

- Через обмеження безпеки браузерів, деякі сайти можуть не відображатися коректно в iframe
- CORS політика може обмежувати доступ до контенту деяких сайтів
- Для кращої сумісності рекомендується використовувати сучасні браузери

## Розробка

Проект створений як демонстрація можливостей створення веб-браузера на чистому JavaScript з інтерфейсом, схожим на Chrome.
